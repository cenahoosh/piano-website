# تمرین پیانو

سایتی برای تمرین پیانو: معلم آهنگ‌ها را اضافه می‌کند و هنرجو هر آهنگ را با **نت** (نت‌خوانی) یا با **نت‌های ریزان** (آبشار) روی کیبورد تمرین می‌کند.

نشانی سایت: **[cenahoosh.github.io/piano-website](https://cenahoosh.github.io/piano-website/)**

## افزودن آهنگ

### ۱. نوشتن آهنگ در MuseScore

برنامه‌ی **MuseScore Studio** رایگان است و از [musescore.org](https://musescore.org) دریافت می‌شود.

- آهنگ را با قالب **Piano** بنویسید: **حامل بالا = دست راست** (آبی)، **حامل پایین = دست چپ** (نارنجی).
- در **File ← Project properties** عنوان (Title) و آهنگساز (Composer) را بنویسید؛ همین‌ها در فهرست آهنگ‌های سایت دیده می‌شوند (فارسی هم درست است).
- یک **علامت سرعت** بگذارید (مثلاً ♩ = 80). بدون آن، آهنگ با سرعت ۱۲۰ پخش می‌شود.

### ۲. خروجی گرفتن

**File ← Export ← MusicXML** و ذخیره با پسوند **mxl** (پیش‌فرض MuseScore).

- نام فایل را **با حروف لاتین و خط تیره** بگذارید، مثلاً `gol-e-gandom.mxl`؛ این نام در نشانی صفحه‌ی آهنگ می‌آید.
- برای هر آهنگ فقط **یک** فایل بگذارید.

| فایل | قابل استفاده؟ |
|---|---|
| `‎.mxl‎`، `‎.musicxml‎`، `‎.xml‎` (MusicXML) | ✅ بله |
| `‎.mid‎` (MIDI) | ❌ اول در MuseScore باز کنید و MusicXML بگیرید |
| `‎.mscz‎` (فایل خود MuseScore) | ❌ اول MusicXML بگیرید |
| PDF یا عکس نت | ❌ در MuseScore دوباره بنویسید (یا با برنامه‌ی رایگان Audiveris تبدیل و بعد در MuseScore بازبینی کنید) |

**فایل MIDI دارید؟** آن را در MuseScore باز کنید (**File ← Open**)، بررسی کنید که دست راست روی حامل بالا و دست چپ روی حامل پایین باشد و ریتم‌ها و سرکلید درست باشند، بعد MusicXML بگیرید. اگر ریتم‌ها شلوغ شد (سکوت‌ها و اتصال‌های ریز)، پیش از باز کردن فایل در **Preferences ← Import** کوتاه‌ترین نت را چنگ یا دولاچنگ بگذارید.

### ۳. گذاشتن فایل در سایت (فقط با مرورگر)

1. به این پوشه بروید: [songs-src](https://github.com/cenahoosh/piano-website/tree/main/songs-src)
2. **Add file ← Upload files**، فایل را بکشید و رها کنید.
3. **Commit changes** را بزنید.

حدود **یک دقیقه** بعد آهنگ در سایت است، هم با نت و هم با آبشار. اگر هنوز نسخه‌ی قبلی را می‌بینید، صفحه را تازه کنید (مرورگر تا ۱۰ دقیقه نسخه‌ی قبلی را نگه می‌دارد).

### سطح آهنگ (اختیاری)

در همان پوشه **Add file ← Create new file** را بزنید. نام فایل همان نام آهنگ است که به آخرش meta.json اضافه می‌شود، مثلاً `gol-e-gandom.meta.json`. در آن این را بنویسید:

<div dir="ltr">

```json
{ "level": 2 }
```

</div>

می‌توانید `"title"` (عنوان) و `"composer"` (آهنگساز) را هم همین‌جا تغییر دهید.

### عوض کردن یا حذف آهنگ

- **عوض کردن:** فایل تازه را با **همان نام** بارگذاری کنید.
- **حذف:** فایل آهنگ (و فایل meta.json آن، اگر هست) را از پوشه‌ی `songs-src` پاک کنید.

### اگر آهنگ در سایت نیامد

اگر فایلی قابل تبدیل نباشد، سایت **نسخه‌ی قبلی را نگه می‌دارد** و چیزی خراب نمی‌شود. علت را در زبانه‌ی [Actions](https://github.com/cenahoosh/piano-website/actions) ببینید: روی آخرین اجرای قرمز بزنید؛ خطا نام فایل و مشکل را می‌گوید.

## برای برنامه‌نویس‌ها

سایت HTML و CSS و JavaScript ساده است و مرحله‌ی ساخت ندارد. Node.js فقط برای تبدیل آهنگ‌ها لازم است:

<div dir="ltr">

```bash
node scripts/convert.mjs                 # songs-src/ → songs/*.json + songs/index.json
node --test scripts/convert.test.mjs     # آزمون‌های مبدل
```

</div>

با هر بار ارسال به شاخه‌ی `main`، گردش‌کار `deploy.yml` (در پوشه‌ی `github/workflows` با نقطه در ابتدا) آهنگ‌ها را تبدیل، آزمون‌ها را اجرا و سایت را روی GitHub Pages منتشر می‌کند. جزئیات فنی در `CLAUDE.md` و ایده‌های بعدی در `IDEAS.md` است.

</div>
